# Flask Student Management System

## Project Description

This project is a simple Student Management System developed using Python and Flask.

It allows users to manage student records through a web interface.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* SQLite

## Features

* Add student records
* View student records
* Update student details
* Delete student records
* Store student data using SQLite
* Web-based interface using Flask

## How to Run

Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python app.py
```

Open the URL shown in the terminal, usually:

```text
http://127.0.0.1:5000/
```
